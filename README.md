# Черновик сайта HASBA AUDIT

Интерактивный черновик новых разделов сайта [hasba.uz](https://hasba.uz) для согласования. Не является рабочим сайтом: материалы и тренинги помечены «Образец», тексты условные.

## Страницы

| Страница | Ссылка |
|---|---|
| Главная с блоком «Проводим обучение» и разделом «Медиацентр» | `#p-home-v2` |
| Медиацентр: лента, фильтр по 7 рубрикам | `#p-media` |
| Главная в текущем виде (для сравнения) | `#p-home` |

Ссылка на страницу — адрес черновика плюс якорь из таблицы, например `…/hasba-draft/#p-media`.

Переключатель страниц — кнопка «Черновик» в правом нижнем углу. Язык (RU / UZ / EN) переключается в шапке.

## Устройство

Весь черновик — один файл `index.html` без внешних зависимостей: шрифты и изображения встроены. Страница закрыта от индексации поисковиками (`noindex`).
